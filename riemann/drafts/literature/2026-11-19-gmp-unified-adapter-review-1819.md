## Direct-source recovery — 2026-11-19

This is a citation repair and confirmation of the existing SPECIALIZE decision, not a new mathematical input. The prior integration history identifies the coupled seams and rejects a driver-only substitution; the current target therefore retains the unified isolated adapter and the same exact slice test. The inspected primary statements and their local applicability are:

- [§6](https://gmplib.org/manual/Rational-Number-Functions): arithmetic expects reduced operands with positive denominator, returns canonical results, and represents zero as 0/1; assignment alone need not normalize. Every constructor/decode seam must establish this invariant before arithmetic.
- [§6.1](https://gmplib.org/manual/Initializing-Rationals): initialize and clear each rational object correctly; raw fractional assignment may need normalization. `mpq_set_str` accepts integer or fraction strings and returns 0 on valid input, -1 otherwise. Check parse status and reject denominator zero before arithmetic; avoid narrow C integer constructors for unbounded Python values.
- [§6.3](https://gmplib.org/manual/Rational-Arithmetic): addition, subtraction, multiplication, division, negation and absolute value have the required rational meanings. The adapter still has to preserve the evaluator's nonzero-divisor conditions, operation selection and ownership; the manual does not validate the bridge.
- [§6.4](https://gmplib.org/manual/Comparing-Rationals): `mpq_cmp` returns a signed ordering indicator, while `mpq_equal` returns a nonzero equality indicator. Do not assume the former returns exactly -1 or +1; macros require attention to repeated argument evaluation.
- [§6.6](https://gmplib.org/manual/I_002fO-of-Rationals): stream output omits `/1` for integers; input may stop before trailing material and raw input may require normalization. Thus a successful stream read alone does not certify the saved JSON schema or full consumption. Exact numerator/denominator round trips remain a local obligation.
- [§5.2](https://gmplib.org/manual/Assigning-Integers) and [§5.4](https://gmplib.org/manual/Converting-Integers): decimal `mpz_set_str`/`mpz_get_str` provide integer digit transfer, with parse-status and output-buffer/allocation obligations. Machine-word and floating conversions can truncate and cannot serialize arbitrary saved integers losslessly. Test signs, zero, denominator-one values and large numerator/denominator values through the actual serializer and decoder.
- [§2.2](https://gmplib.org/manual/ABI-and-ISA), opening general requirements: linked code must use a common ABI and the generated header reflects limb choices. This does not identify the installed build; header/library/compiler compatibility still needs local verification before trusting a bridge.
