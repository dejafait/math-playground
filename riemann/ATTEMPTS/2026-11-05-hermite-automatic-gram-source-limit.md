# Hermite criterion does not import the proposed theta Gram identity

Step495's [completed source comparison](../drafts/literature/2026-11-05-central-hermite-theta-gram.md)
checks Nathanson's full Hermite criterion proof, GORZ's exact low-degree
theorem/convention and Forrester's determinant-integration proof. It is
a literature-only source-scope negative, not a new mathematical lemma.

WHY IT FAILS: Hermite's nonnegative root-evaluation squares use real
roots, and Andreief requires already supplied function families realizing
the matrix entries. Neither identifies nonlinear coefficient Newton
sums with raw theta moments. Using a positive matrix square root,
unknown real-root measure or unknown minor signs would pay for the
desired positivity with itself. Central degree-six hyperbolicity is
already covered by GORZ Theorem2; repeating that check would not provide
the requested independent identity. This parks automatic imports only,
not every theta Gram construction. The exact product-kernel diagnostic
in [the new assessment](../drafts/literature/2026-11-05-central-hermite-product-kernel-test.md)
is uncomputed and awaits separate approval. L766's different Toeplitz
representation stop is preserved; no negative integrated form or RH
conclusion is asserted.
