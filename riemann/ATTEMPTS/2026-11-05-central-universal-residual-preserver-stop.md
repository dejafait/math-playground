# Central matched residual: universal preservation fails — step485

The approved fixed-prefix test is resolved in
[C792a](../lemmas/C792a-central-residual-universal-preserver-obstruction.md).
This is an informative negative for a sufficient fallback, using known
multiplier methods; it is neither a disproof of RH nor a new general
root theorem.

WHY IT FAILS: Exact matching gives the first five diagonal entries equal
to one, while L792's strictly positive mismatch makes the sixth smaller
than one and still positive. The translated binomial witness has four
nonreal image roots. Restriction carries this failure to every larger
diagonal operator retaining the same prefix. Arbitrary later entries
cannot repair it. The particular model-to-actual transfer remains valid
in degree five, so future transfer must exploit that family or other
independent structure. This stop is not a ban on model-specific bounds
or a prefix that actually changes with the degree.
