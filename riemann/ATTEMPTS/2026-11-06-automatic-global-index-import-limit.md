# Automatic global complex-point obstruction is not a source import

6 November 2026. The primary-source comparison is recorded in
[the global-index assessment](../drafts/literature/2026-11-06-global-complex-point-index-scope.md).
This is a source-scope limit, not a counterexample to contour existence.

**WHY IT FAILS.** Lai's global embedding formula gives two zero signed
totals for a torus. Neither it nor the inspected cancellation theorem
assigns signs to the actual full-form contacts or guarantees positivity
and the prescribed collar jointly while isolating them. The universal class
identity remains meaningful for a nonisolated set, but its decomposition
into signed local terms needs justification. Thus generic isolation
cannot be silently imported as an admissible surface deformation.
The proposed fixed-surface Gauss-map test is a different, unproved
mechanism; this limit is not a ban on index methods.
