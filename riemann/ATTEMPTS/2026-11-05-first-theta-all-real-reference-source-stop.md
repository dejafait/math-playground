# First theta summand as an all-real reference — step571

WHY IT FAILS: The primary finite-sum statement in Pólya, *Acta Math.*48
(1926), Section4 pp.315–316, gives infinitely many zeros but only finitely
many real zeros for finite sums of the full theta summands. It includes
the one-term object. Step572 confirms the local scalar convention:
f_N=2Φ_N and F_N=4T_N, so the citation applies exactly.
[L234](../lemmas/L234-finite-theta-truncations-have-negative-associated-tails.md)
already records the canonical endpoint/first-associated-spectrum
obstruction, whose proof should not be duplicated. The complete
[source comparison](../drafts/literature/2026-11-05-first-theta-summand-relative-minor-scope.md)
parks the all-real-reference premise and records the matrix perturbation
scope. It does not determine a particular reference coefficient minor,
exclude every finite-order signed comparison, or challenge actual-Xi
signs or RH. Reopening requires an explicit restricted sign/margin or
a mechanism accommodating nonreal reference zeros; scalar moment
closeness and the known finite endpoint failure are not new input.
