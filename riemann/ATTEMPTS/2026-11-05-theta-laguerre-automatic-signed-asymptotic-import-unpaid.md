# Uniform Laguerre kernels: automatic signed-integral import unpaid

Step561's [source comparison](../drafts/literature/2026-11-05-theta-laguerre-uniform-oscillatory-localization.md)
locates complementary Bessel/Airy argument domains and additive
envelope errors. This is source information, not a newly proved
obstruction or a sign theorem. No lemma or mathematical script changed.

**WHY IT FAILS.** A pointwise error measured against an oscillatory
kernel's positive envelope does not provide a relative error against
the signed theta average. The sources inspected do not supply the
independent nonzero barrier margin, theta-integrated error or
degree-uniform complementary-support comparison needed for that import.
Fixed-degree integrability in L795 cannot pay these uniform demands.
This parks the automatic sign inference, not all use of Laguerre
asymptotics. Reopening a sign import needs those missing estimates;
repeating the same theorem-domain screen is insufficient. The nominated
absolute logarithmic-window test is a narrower, independently testable
interface and would leave the signed margin unresolved.
