# Uniform axial ordered-action quadratic coefficient

WHY IT FAILS: [L027](../lemmas/L027-axial-ordered-action-wick-loop-growth.md)
proves that the actual restricted quadratic Wick coefficient 6 K:C_p
on interior (1,mu) plaquettes has norm Theta(a^(-1)) in the straight
forest. Thus contracting the raw loop with the ordered tensor does
not produce a uniform O(1) local coefficient. The common path slice
is bounded, but the curvature-square coefficient grows. This stops
only the tensor-only absolute bound; the actual signed W_(i,p)
contraction, plaquette summation, other pairing class and L019's
cross-group cancellations remain unresolved. It does not establish
a divergent probe response or failure of the full target. Use the
exact active two-by-two contraction to test those remaining factors.
