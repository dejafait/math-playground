# An axial-profile or absolute-norm power gain for the high first pair

WHY IT FAILS: [L077](../lemmas/L077-first-pair-axial-completed-principal-test.md)
completes L070's frozen transverse principal test with the actual
odd axial component-1 profile and the full pinned Dirichlet inverse.
Retaining the axial curl derivative contracts the inverse exactly
to sum_s s h_s, whose physical moment is positive. A fixed high
transverse frequency band then has a strictly nonzero N³ coefficient
for R.v>0; bounded curvature subtractions contribute only O(N²).
Thus these axial features alone cannot give an O(N²) estimate
uniformly over smooth frozen coefficients. This parks only that
profile-plus-absolute-norm closure. The test replaces the transverse
geometry and coefficients explicitly, so it does not prove growth
or rule out an O(N²) bound for either actual signed probe trace.
The next discriminating test must retain the actual exterior heat
contraction and variable coefficients to identify or cancel a leading
functional. ATTEMPTS/019–024 and L076's low left-sector estimate remain.
