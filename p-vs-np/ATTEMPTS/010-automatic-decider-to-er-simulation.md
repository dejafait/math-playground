# Automatic transfer from decider traces to extended resolution

Tested 2026-09-25. The proposed shortcut checks a rejecting computation of an arbitrary correct SAT decider and treats that check as supplying a polynomial-size refutation in a prescribed system, especially ER.

**WHY IT FAILS.** [L011](../lemmas/L011-decider-proof-systems-and-simulation.md) constructs the valid trace system R_A, but under a globally polynomial-time A its simulation by ER is equivalent to polynomial boundedness of ER itself. That bound is not supplied by transition checking or by the existential Cook–Reckhow theorem. A full-truth-table target system provides an actual counterexample to the system-independent inference: it requires exponentially many rows on opposing-unit contradictions with polynomial rejecting traces. This counterexample is easy for ER and does not disprove an ER-specific simulation. The stop concerns the claimed automatic transfer; a new ER simulation argument remains possible, but must justify its proof lengths and semantic correctness step. Polynomial-size formulas encoding rejection soundness have been constructed, with no polynomial ER refutation bound for them.
