# Attempt 019 — Polynomial common-order OBDD width for all supplied short ER proofs

The proposal was to use L026's diagram-based construction as a universal way to supply L025's reduced data, by bounding the required common-order width polynomially in the full binary length of every supplied ER refutation. Definitions must actually participate in the final inference ancestry; unused-definition padding does not test this proposal.

**WHY IT FAILS.** [L027](../lemmas/L027-used-er-extension-every-order-obdd-width.md) embeds the known HWB every-order OBDD separation in an explicit polynomial-bit signed-AND ER proof. Every introduced extension has a defining clause and a derived signed unit in the final ancestry, and the HWB output retains all n original inputs on every assignment. The imported exponential node lower bound forces dense width 2^(Omega(n)) in every order, while T=O(n² log(n+2)). Thus this universal polynomial-width premise fails even for genuinely used extensions. The same original CNF has an immediate alternative refutation and a three-node arithmetic certificate. This stop applies to arbitrary **supplied-proof OBDD width**, not to L026 on its promised class, choosing another proof, other reduced data, all certificates or unrestricted SAT complexity. The next proposed mechanism permits compact reduced arithmetic circuits without OBDDs and needs its own source assessment.
