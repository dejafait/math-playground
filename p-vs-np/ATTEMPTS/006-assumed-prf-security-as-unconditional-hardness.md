# Assumed pseudorandom security as an unconditional MCSP lower bound

Tested 2026-09-25. The restriction test asked whether a hypothetical polynomial-time MCSP_u decider distinguishes polynomial-length tables generated by a keyed function, and whether the resulting security implication offers an unconditional P-versus-NP route.

**WHY IT FAILS.** The quantitative reduction in [L007](../lemmas/L007-mcsp-prf-restriction-and-premise.md) works: logarithmic input restriction gives polynomial cost in key length and distinguishing advantage tending to one. But the security premise is unproved here and already supplies P!=NP without an MCSP lower bound. The language of explicit restricted tables generated by some key has direct NP certificates; under P=NP, its polynomial-time decider would distinguish the keyed distribution from uniform tables. Thus the conditional implication cannot be promoted to an unconditional separation by treating security as an established input. This records that specific limitation, preserves the valid conditional reduction, and makes no claim that all cryptographic or MCSP mechanisms fail. Security against a restricted model or one fixed polynomial exponent would also leave the unrestricted conclusion unsupported.
