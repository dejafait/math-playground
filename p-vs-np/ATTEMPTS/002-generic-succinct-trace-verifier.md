# Generic validation of circuit-described computation traces

Tested 2026-09-24. The proposed shortcut was to supply a small circuit giving the configuration at each binary time address, then check its initial state, final state, and every consecutive transition in time polynomial in the circuit description and binary horizon. Its intended downstream use was a fixed polynomial-time NP verifier for computations used in uniform diagonalization.

**WHY IT FAILS.** [L002](../lemmas/L002-succinct-trace-validity.md) reduces circuit tautology to this supplied-description validity problem even when a fixed machine accepts after one step, every configuration encoding is legal, and both endpoints are correct. Thus a general deterministic polynomial-time validator would prove P=NP; sound and complete polynomially bounded NP certificates for every valid supplied description would prove NP=coNP. Neither collapse is established. The proof also gives only two bad transitions among exponentially many, so uniform local sampling does not discharge the obligation. This rejects an unproved verifier claim, not the existence of all possible succinct certificate systems: the underlying computation here has an obvious valid canonical descriptor. A restricted certificate language would need its own soundness, completeness for the intended computations, and fixed polynomial verification bound. The stop is specific to the generic-validator shortcut and does not ban further diagonalization research.
