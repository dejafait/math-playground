# Literal extension substitution as a polynomial ER-to-tree translation

Assessed 2026-10-04 under the ready SPECIALIZE review. [L019](../lemmas/L019-er-literal-substitution-cost.md) gives the complete conditional bound and the used-extension counterexample.

**WHY IT FAILS.** Eliminating every extension by its occurrence tree permits the imported Frege-to-formula-IPS and balancing stages at cost polynomial in the original binary length T plus unfolded size U. The latter parameter is uncontrolled: a valid 6m-1-clause ER family has T=Theta(m log(m+2)) but exponential U, even when counting only lines in the final contradiction's ancestry. Every extension definition is used, so removing irrelevant definitions does not remove this counterexample. This stops claiming a polynomial translation from this literal-substitution construction without a size premise. It does not lower-bound optimized proofs or certificates; the original CNF has a constant refutation and a seven-node formal certificate. Boolean simplification, alternative translations and the general reverse theorem remain open. Retaining circuit sharing would change the target and must be screened separately; it would still leave the passage back to tree certificates unresolved.
