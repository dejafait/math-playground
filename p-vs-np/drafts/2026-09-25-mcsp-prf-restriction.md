**Gap, intermediate target, and test.** MCSP_u has NP witnesses but no unconditional decision lower bound here. Test whether its hypothetical polynomial-time decider can distinguish restrictions of an efficiently evaluated keyed function from a truly random function. The intended intermediate result is a uniform polynomial-time oracle reduction with explicit table length, gate threshold, and nonnegligible advantage. This would explain how a structured source of small circuits can supply a recognition-hardness implication. The reduction fails its quantitative test if enumerating the restricted table exceeds polynomial time in key length or its threshold does not cover the keyed functions. Even if it works, assess whether the security premise already implies the main separation, so that the result remains conditional.

**Initial saved derivation.** Let F_K map k-bit inputs to one bit, with k-bit keys and one uniform polynomial-time evaluator. Its hardwired restrictions have AND/OR/NOT circuits of size at most c k^d, absorbing the gates needed to implement constants. Choose the fixed integer a=d+2. For k>=2, take r=min(k,a ceil(log_2 k)) and N=2^r. Eventually r=a ceil(log_2 k), while for every k, N<=2^a k^a. Query all inputs z followed by k-r zeroes, in lexicographic order, and run the supposed MCSP_u decider on threshold s=floor(N/(32r)). Eventually c k^d<=s. L006 then bounds random-table acceptance by 2^(-3N/4), whereas every keyed table is accepted. Query writing costs O(kN), also polynomial in k. The adversary's degree may depend on the fixed evaluator and the fixed MCSP algorithm, which is permitted by security against every polynomial-time oracle algorithm.

**Initial security-premise check.** Define the explicit-table language of restrictions generated by some k-bit key, with k in a unary header and a table of the prescribed length N(k). It has an NP verifier that guesses the key and recomputes all N outputs in polynomial time. At most 2^k tables can be generated. If P=NP, a polynomial-time range-membership test distinguishes the keyed tables from uniform tables with advantage at least 1-2^(k-N). Thus the security premise itself would imply P!=NP without any MCSP hardness theorem. This was the proposed discriminator for assessing the reduction as an unconditional route.
