# Archived unary padding audit sketch — 2026-09-25

The preceding checkpoint selects unary padding as a proposed repair of the fixed-verifier-exponent gap. The shared rules, local overview and DAG, existing changes, earlier trace proof, and failed approaches were inspected. The current Clay page and Cook's official statement were rechecked; the target remains ordinary uniform P versus NP.

**Gap and intermediate target.** A diagonal construction must disagree with each candidate decider on the very input whose membership is being defined, while admitting certificates bounded by C(N+1)^d for fixed C,d in the full input length N. Test whether unary padding can make explicit computation certificates satisfy both requirements. Success would supply an NP-membership component; a complete separation would still require soundness, completeness, and disagreement with every polynomial-time decider. The previous trace-validity result addresses arbitrary succinct descriptions, not this explicit-trace mechanism.

**Discriminating test.** Define a self-delimiting core z encoding a deterministic machine M and a unary exponent k, and a full input x=z1^r. Compare a clock (N+1)^k for M(x) with a clock (|z|+1)^k for M(z). Reject padding as this repair if the first version has yes-instances whose actual rejecting runs exceed every fixed polynomial certificate bound, and the second version has a polynomial-time decider after enough padding. Comparing a nominal upper clock to a verifier bound alone would not prove that actual runs are long.

**Completion.** The working reasoning was saved before the detailed proof. [L003](../lemmas/L003-unary-padding-diagonalization.md) completes both tests: actual deliberately long rejecting runs defeat every fixed polynomial explicit-transcript bound in the full-input construction, while the shorter-core construction has a uniform polynomial-time decider. The proof checks self-delimiting parsing, timeout conventions, clock constants, actual rather than nominal running times, and the distinction between the two inputs. It also applies the shorter-core construction to its own decider to exhibit the absence of a contradiction. No NP separation or full candidate is asserted. This archive carries no unfinished proof or current action.
