# C046a — Clause-placeholder elimination from an arbitrary supplied affine ABP

## Hypotheses

Work in the free associative algebra over F₂. Let F be an explicitly encoded width-at-most-three CNF, retaining its written clause/literal order, repetitions and complementary literals. List exactly its original variable identifiers as x₁,…,x_n, with complete name payloads. For each written clause j set c_j to the ordered product of literal falsity factors v(x_i)=1+x_i and v(¬x_i)=x_i. Define s_j=1+c_j and f_F=s₁…s_m; empty products are 1. These are L041's ordered translation, as used in L045 and L046.

Let B_x be the ordered list of x_i²+x_i and x_i x_k+x_k x_i for i<k, and A the written clause polynomials c_j followed by B_x. Supply an independent placeholder t_a for each position of A. Repeated clause occurrences remain separate positions and separate placeholders. The notation y_j,σ_i,τ_ik below denotes the corresponding t_a by its axiom position; it does not require changing its stored identifier.

Supply an explicit finite acyclic affine-F₂ ABP C over x,t with designated entrance and exit. Its polynomial is the sum of ordered edge-label products over designated accepting paths, with the empty path contributing 1. All labels and their constant bits and symbol coefficients/occurrences are explicitly written. Parallel/zero edges, dead vertices, unequal path lengths, nonextremal or coincident endpoints, mixed labels, nonlinear placeholder paths and cancellation are permitted. Implicit graphs and circuit-valued labels are excluded. Assume both formal free-algebra identities

    C(x,0)=0,                    C(x,A(x))=1.

Fix the same ordinary explicit binary list encoding throughout. Set Q=2+|F|+|C|+|A|, counting complete graph records, labels, original names, alphabets, axiom/placeholder dictionaries, endpoints and framing. All declared items are actually written; no implicit symbol range is allowed. Use the constructions and bounds established in L046 and L045.

## Conclusion

There is a deterministic polynomial-bit-time construction of an explicit acyclic affine-F₂ ABP H using exactly the permitted original alphabet x and Boolean/commutator placeholders σ,τ, with formal identities

    H(x,0)=0,                    H(x,B_x)=f_F.

Its complete output length, including original names, the complete B_x and placeholder dictionaries, unused permitted symbols and endpoint/list framing, is at most KQ⁸⁰ for one absolute encoding-dependent constant K. Every accepting path contains exactly one placeholder-bearing edge. The constructor does not test the supplied identities. Neither H nor the intermediate certificate is required to equal C as a free polynomial.

This is a conditional application of existing local results for an already supplied graph. It removes L045's pathwise input restriction. It provides no original-axiom ABP from arbitrary ER data, universal witness bound in |F| alone, faithful representatives, ER polynomial boundedness, certificate finder for arbitrary UNSAT formulas or unrestricted SAT decision/separation. A separate critical audit on 2026-10-10 found no substantive error; the composition checks are recorded below. Classification REPRODUCTION records the theorem application and accounting, not progress beyond the sources checked or certified originality.
