# L064 — Supplied finite backward-zero chain in one proof store

## Hypotheses

Use the native ax-1/2/3 and MP calculus, exact fully expanded X,E,P,Y,Z and literal NOT/OR image τ of L063. All names are nonempty ASCII alphanumeric/underscore payloads; q and all auxiliaries are ordinary free variables. Receive native proof packages only. No completeness claim for independently supplied NOT/OR inputs is made.

Supply N≥2 identical written suffix trees S_v throughout the chain, one q, an ordered list of n≥0 letter-variable occurrences x_b, β:N×1, and G_b:N×N for all b. Supply all N complete coordinate packages with the exact L063 endpoints, including every unused/deep record. Each package occurrence is paid and retained once, even when paths, contents, suffixes or names coincide. The fourteen fixed laws of L063 have checked complete native strings and literal images; an arbitrary caller library is excluded.

Supply an explicit list of dimensioned tables R_0,...,R_d, d≥0, with k_i≤N rows of N literal bits and k_d=0. For every indexed row r=(R_i)_j, i<d, supply T_(i,j,b):1×k_(i+1) for all b and require the finite F₂ checks

    rβ=0,   rG_b=T_(i,j,b)R_(i+1).

Empty levels retain their dimensions and framing; the terminal level has no rows or T obligations. No next-row proof, terminal proof, Q7/Q8 proof, closure/basis finder, identity/PIT/UNSAT oracle, L059 guard or external cache is supplied. The full original uncompressed explicit input length Q counts tables, level/row framing, suffix/letter/name trees, all coordinate proof occurrences and reference fields, and the fixed library source. No existence premise for such coordinate/chain data is established.

Let m=Σ_(i<d)k_i. Let I be the total coordinate-record count, K_j their total formula/substitution nodes and δ_j their maximum depth in format j=native,image. Let t_j≥1,d_j bound nodes/depth of each written suffix, letter,Y,Z. B≥1 bounds every supplied/library ASCII payload. On the complete fixed library let L be the maximum line count, and D_j,S_j bound depth and total formula/substitution nodes of one record. These are original-input/library statistics, never statistics of derived row packages.

## Conclusion

The single-store construction `scripts/backward-zero/chain.py:compile_chain`, using the extracted internal `build.py:emit_transition`, retains all coordinate records once and gives exact earlier records for each indexed nonterminal row:

    E(W(r;S),Q7), E(Q7,Q8), E(Q8,Z), E(W(r;S),Z),

with Q7,Q8 exactly as in L063 for R_next=R_(i+1), T=T_(i,j,*). All requested row endpoints occur in one complete primitive stream and in its line-by-line literal image. Actual selected next-row conclusions are referenced from this same store. Rows and levels do not change the written suffix interface or nest earlier proof text inside terms.

Set

    D=2+N+n+max_i k_i,  h=ceil(log₂D),
    V=2^(3h+4),  H=9h+20,  E₀=10000 V²(H+1)²,
    G=m(L+1)E₀,  J=I+G,  P_j=8·4^(H+1)(t_j+1),
    F=256+64 ceil(log₂(J+2)),  A_j=max(K_j,S_jP_j).

For each format the complete serialized proof satisfies

    lines ≤ J,
    depth ≤ max(δ_j,D_j+c_jH+d_j),
    record nodes ≤ A_j,
    proof bytes ≤ (B+4)[K_j+G S_jP_j+A_j]+(J+2)F,       (1)

where c_native=3,c_image=6. Its compact indexed locations file, with coordinate import offsets/counts/roots, every level dimension and each row's start/end/four roots, costs at most

    (m+d+1+N+2)[512+128 ceil(log₂(J+d+1+m+3))] bytes.    (2)

Thus the proof plus locations has one fixed polynomial full-bit bound in Q (for example ≤C(Q+2)^30 for a fixed C). Construction, reception and checking admit polynomial abstract bit time. Python recursion/resource limits are not an all-input execution guarantee.

For d=0 or m=0, no row zero theorem is requested. The complete output consists of the retained coordinate proofs, with its ordinary proof header naming the last coordinate conclusion. Bound A_j in (1) also pays this header. This does not invent a terminal zero theorem.

This is implementation/reproduction of a conditional local interface; the separate step-200 critical audit below found no substantive defect. It is not certified original mathematics or a P-versus-NP candidate. Coordinate/closure existence, ordinary-input completeness, both complete identity receivers, the whole L055 receiver, certificate existence, ER/W/V/U and SAT transfer remain open.

The final coordinate roots are literal records of this store. There are no imported next-row records.

The invariant before level i is: for every indexed row at every already processed level ℓ>i there is a registered handle whose owner is this store, index is (ℓ,j), and root is an actual earlier primitive record with exact endpoint E(W((R_ℓ)_j;S),Z). ### Port of the transition body, without recursive packages

Before each row emission, `emit_transition` validates q, coordinate/next-root counts, integer roots less than the current row start, and all exact coordinate/next-row endpoints. Its body is the L063 assembly with `inputs[v]` replaced by the already imported coordinate root and `inputs[N+j]` by the validated next-row root. It neither constructs a Store nor imports packages. The old `compile_one` remains a fresh-package wrapper around that body.

Every fixed-instance copy reconstructs each primitive inference under simultaneous substitution. MP adds the exact consequence from actual earlier records. A cache hit is permitted only for an identical law/argument tuple already copied in this same store. Initially the cache is empty; only such locally checked copies add entries. Therefore each cache hit refers to a paid valid earlier record with the identical formula, and introduces no external premise. Propositional simultaneous substitution needs no name freshness; replacements are not recursively resubstituted.

`combine` references the earlier child equivalences; its term arguments are just their endpoints' selected suffix subtrees. The four tagged normalizations, distributions, zero erasures, permutations/cancellations and paid reassociations are exactly those proved in L063. They inspect row/suffix terms and finite tags, not prior proof text. For the first comparison Y parity is rβ=0 and tagged product parity is (rG_b)_w. For the second comparison that parity is Σ_ℓ (T_b)_ℓ (R_(i+1))_(ℓ,w), identical by the checked bit identity. Tags preserve occurrence indices even when native formulas coincide. Thus both comparisons have the exact same normal form and give E(L,Q7), E(Q7,Q8).

For each b combine precisely the selected earlier row records E(L_j,Z). Paid zero-list erasure gives E(W(T_b;[L_j]),Z), followed by product congruence and prod_zero. Combine these n product conclusions and erase the outer zero list to give E(Q8,Z). Finally the two paid transitivity compositions give E(L,Z). No earlier equivalence formula or proof package is installed as a new leaf; next-row syntax is always W((R_(i+1))_j;S), reconstructed directly from supplied bits and the fixed written S.

An empty selection uses Bal([])=Z and paid reflexivity. Singleton selections use the exact earlier root. Empty n gives Q7=Q8=Z. Empty next levels force rG_b=0 and require no next-row proof. r=0 is included. A terminal table has no rows to prove. No assumption that every β_v is zero is used: an even selected constant parity suffices. All this is inference induction on the actual emitted records, not an application of a Boolean-zero oracle.

### Original-input bound and literal image

L062's audited per-transition geometry depends only on N,n,k, the fixed suffix/letter/Y/Z trees and their atomic occurrence tags. Replace its local dimension by the global majorant D.
