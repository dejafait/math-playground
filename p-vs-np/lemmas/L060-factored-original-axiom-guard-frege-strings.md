# L060 — Primitive guards for exact factored original axioms

## Hypotheses

Use L048's unconditional ordered original-axiom definitions and occurring-variable dictionary. Supply a nonempty width-at-most-three CNF with no empty clauses. Every signed literal occurrence, actual binary OR bracketing, ordered clause position, binary conjunction tree, raw ASCII variable name, dictionary entry and A-position placeholder role is written. As in L056, accepted variable names (including q) are nonempty ASCII alphanumeric/underscore strings, exactly `[A-Za-z0-9_]+`; other payloads require a separately charged injective encoding before reception. The conjunction tree has the clause positions 0,...,m−1 in that order, each exactly once; its depth is unrestricted. Equal clauses have distinct positions. Repetitions and complementary occurrences are retained. Original and placeholder role namespaces are distinct, even if their payload strings coincide. No unsatisfiability assumption is made.

This result accepts **factored** clause trees: a positive occurrence x has falsity factor 1+x and a negative occurrence NOT x has factor x; the product has exactly the corresponding clause's binary OR bracketing and literal order. The Boolean tree is (x*x)+x. The commutator tree is (x*y)+(y*x), for the dictionary's actual i<k pair positions. A consists of all clause trees, then all Boolean trees, then all pair-once commutators in L048 order. All expected trees and dense position names t_1,...,t_|A| are explicitly supplied and validated. Arbitrary same-polynomial expressions, other product bracketings and expanded word-list consumers are outside this reception contract; those consumers require a separately paid bridge.

Fix an explicitly written ASCII name q, with no freshness condition. In L056's native ax-1/2/3/MP calculus expand literally

    T=(q→q), Z=NOT T,
    X(U,V)=((U→V)→NOT(V→U)), E(U,V)=NOT X(U,V),
    P(U,V)=NOT(U→NOT V), OR(U,V)=(NOT U→V).

Eval sends arithmetic 0,1,sum,product to Z,T,X,P without changing the accepted trees. Φ_F is the actual CNF conjunction/OR tree using P/OR and its signed literals. The image tau sends NOT U to NOT tau(U) and U→V to NOT tau(U) OR tau(V), without simplification. Only this literal image calculus is claimed, not arbitrary independently supplied NOT/OR input completeness.

For each format j let g_j,dg_j count nodes/depth of Φ_F, e_j,de_j bound nodes/depth of every Eval(A_a), and z_j,dz_j count nodes/depth of Z. Let B≥1 bound all raw name payload bytes, including fixed schematic names. Complete input includes all tree, name, sign, position, axiom and namespace records. Every formula/substitution occurrence and reference is paid; compressed archive size is not proof length.

## Conclusion

For every actual original-axiom position a, there is a complete assumption-free primitive native proof with exact last formula

    Φ_F → E(Eval(A_a),Z),                              (1)

and its line-by-line literal image. This includes each repeated equal clause position separately. The construction checks the complete fixed strings before copying them, preserves every written fixed record and relocates references in fresh append-only state. It emits no supplied-premise, definition, truth-table or semantic-equivalence rule.

The 28 checked fixed strings have common constants

    L=2223,
    (D_native,S_native)=(23,2768),
    (D_image,S_image)=(30,3882).

D bounds formula and declared substitution depth; S bounds their combined nodes per fixed record. Set

    J0=L+m(2L+2),
    W_j=2g_j+2e_j+2z_j+16,
    d_j=max(dg_j,de_j+6,dz_j+6),
    F0=256+64 ceil(log₂(J0+2)).

Each output has at most J0 lines, depth at most D_j+d_j, combined record nodes at most S_j W_j, and uncompressed bytes at most

    (J0+2)[(B+4)S_j W_j+F0].                         (2)

The whole ordered list costs at most |A| times (2), with at most |A|J0 primitive lines; multiply bytes by eight for bits. One fixed polynomial bounds construction/checking time and full-bit output in the complete supplied package. All-size reasoning is below; bounded complete checks are evidence for the implementation, not its all-size proof. The separate step-186 critical audit below corrects the external image ax-1 subcalculation and clarifies the name grammar; all displayed bounds survive. This is an implementation/accounting reproduction of known propositional laws, without certified originality or a P-versus-NP conclusion.

### Reception, copying and actual-tree projection

`scripts/original-axiom-guards/endpoints.py` imports no emitter/planner. It checks exact dictionary/position/tree shapes, ASCII payloads, literal signs and bounded arities. It rebuilds A from the supplied ordered clauses/dictionary and rejects a different tree even if polynomially equal. Typed JSON comparison prevents Boolean true from masquerading as arithmetic constant 1. Its independently constructed goals follow the supplied tree precisely. Placeholder names are position-role data in a disjoint namespace; they are not inserted as propositional variables or identified with originals.

For each output start a fresh append-only proof store. A fixed string is loaded/check-validated in full, then each axiom is reconstructed from the simultaneously substituted declared fields. Each MP reference k is relocated to the actual earlier copied record. The reconstructed conclusion must equal substitution into the original conclusion. Induction on records proves the copy is primitive and retains every fixed record, including ones not on a shortest derivation. Substitution returns the replacement tree at a variable without recursing into it, so coincident A/B/C/q and actual input names impose no freshness condition. Fixed and growing paths are distinct. The copy code is reused from `scripts/balanced-coordinate/aggregate.py`, but no coordinate-combination conclusion is used: this elementary inference induction also proves the particular copy property needed here.

For clause position a, first copy identity with argument Φ_F, giving Φ_F→Φ_F. Walk the unique path to that exact clause occurrence in the actual conjunction tree. At a current node P(U,V), choose child H=U or H=V. Copy the corresponding projection, giving P(U,V)→H, and composition with arguments Φ_F,P(U,V),H. Two actual MPs, with the existing Φ_F→P(U,V) and the new projection, yield Φ_F→H. Descending one edge removes one conjunction node. After its path length k_a≤m−1 the endpoint is precisely Φ_F→clause_a. The one-clause case has k_a=0 and needs only the initial identity.

Copy the clause template for its actual arity, signs and bracketing, simultaneously substituting each original name and q. Repeated/complementary literal names are substitutions into separate occurrence slots, not simplifications. The template gives clause_a→E(Eval(A_a),Z) literally. Copy composition with arguments Φ_F,clause_a,E(Eval(A_a),Z), and use two MPs to obtain (1) as the actual last record. Distinct equal clause positions each receive their own output and unchanged dictionary entry.

For a Boolean or commutator position, copy its unconditional fixed E(Eval(A_a),Z), with the actual dictionary operands and q. Append ax-1 with B=Φ_F and one MP. Its last record is (1). The variable assignment remains free and no CNF satisfaction/unsatisfiability test is made. These three branches cover the entire ordered factored list.

### All-size copying ledger

An initial identity costs at most L lines. Each of k_a projections costs two whole fixed strings and two external MPs, at most 2L+2. The final clause/composition pair costs another 2L+2. Hence at most L+(k_a+1)(2L+2)≤J0 lines. A Boolean/commutator proof costs at most L+2≤J0. All output copies are complete and no cache prunes records. At most |A| independent outputs give |A|J0 lines.

Projection/composition arguments along the path are Φ_F or actual subtrees thereof. Clause-template arguments are original variable leaves and the written q; their internal bounded evaluations occur within the fixed record. The final composition's last argument is E(Eval(A_a),Z). Native E has 5+2|U|+2|V| nodes; its literal image has 8+2|tau(U)|+2|tau(V)| nodes and depth overhead at most six. Thus every substituted argument has at most W_j nodes and depth at most d_j. Arguments are formula trees, never prior proofs or previous guarded equivalence conclusions inserted into expanding contexts. In particular the possibly deep Φ_F is a separate template parameter, never an operand of a growing XOR.

A fixed record with s connective nodes and v variable occurrences, counting its declared substitution fields, has s+v≤S_j. Replacing each variable leaf by an argument of at most W_j nodes gives s+vW_j≤S_jW_j. Substitution adds at most d_j to depth D_j. External MP conclusions are subformulas of an already bounded instantiated implication. Write U=E(Eval(A_a),Z), G=Φ_F in the current format. The additional Boolean/commutator ax-1 record has exactly 3|U|+2|G|+2 nodes natively, including its two substitution fields, and 3|U|+2|G|+4 nodes in the literal image. Indeed its image formula is OR(NOT U,OR(NOT G,U)). Its depth is at most d_native+2 natively and d_image+3 in the image. Thus the record has at most 5W_j+4≤S_jW_j nodes, and depth below D_j+d_j. Its declared fields are paid separately without importing an enlarged fixed-library constant. Step 186 corrected the earlier use of the native +2 node/depth overhead for both formats; neither displayed bound changes.

Each ASCII name occurrence costs at most B bytes and operator punctuation at most three, so B+4 per node covers serialized formula/substitution strings. A record has at most three substitution keys or two references below J0, plus fixed JSON keys/tags/framing. F0 dominates this nonformula cost, including decimal reference lengths. J0+2 records cover the header's fully written endpoint and framing as well as every line. This proves (2), with all names, substitutions, unused fixed records and relocated references charged.

Let Q=2 plus complete supplied input byte length. Since trees, occurrences, every axiom position and names are written, m,|A|,B≤cQ. Expansion of the actual native CNF uses each child once under P/OR, so g_j≤cQ in either format. Every accepted axiom has bounded arity/shape, so e_j,z_j≤cQ (in fact a constant node bound suffices); depths dg_j,de_j,dz_j≤cQ. Therefore J0=O(Q), W_j=O(Q), and |A| times (2) is O(Q^4) after fixing one input-independent multiplier. Fixed archives add a constant. Bit lengths obey the same polynomial; compression is irrelevant. A stack-based tree walk and complete string copy/checking run in polynomial bit time in these explicit bounds. The concrete Python implementation is bounded evidence and may meet interpreter recursion/resource limits; it is not certified for every interpreter or abstract input length.
