# A quotient-only objection to input membership

Assessed on 2026-09-25 in the [hull quotient audit](../drafts/2026-09-25-hull-quotient-audit.md). The tested objection was that collapsing the output hull, or forming a loop after collapse, necessarily invalidates the input-degree comparison. [L003](../lemmas/L003-hull-collapse-and-degree-membership.md) gives the precise elementary quotient calculation; the [source record](../foundations/02-comparison-claim-and-sources.md) retains the categorical qualifications of the original construction.

WHY IT FAILS: collapse loses exact volumes but still detects containment, and a compatible collapsed-degree map exists for full p-adic lattices. Conversely, an unmarked identity loop alone does not put a specified input in the distinguished collapsed class. Neither observation decides whether the actual formal transport carries the q-pilot there. Substituting a bare set quotient for that transport removes hypotheses; treating a formal intersection as an ordinary nonempty set also changes the assertion. The elementary models therefore furnish no essential IUT flaw. This stops the quotient-only shortcut and the current bounded exploration sequence; it does not rule out a test of the actual structure morphisms with a new discriminating calculation.
