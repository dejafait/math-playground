# Degree-27 sufficient multiplication inclusion

The approved target was 18pi(O union J) subset J, for pi^27=3 and J=log(O^times), as a sufficient radius-81 test via L015.

**WHY IT FAILS:** [L016](../lemmas/L016-degree-27-exact-logarithm-membership-fails.md) gives a functional integral on the complete logarithm image that excludes the actual point 18pi log(1+pi), with a rigorously controlled infinite tail. The ideal branch passes; the logarithm branch fails. Stop this inclusion mechanism in this packet. The original target and the coarse bound are not refuted: membership in this particular invariant lattice is sufficient, and its failure supplies no actual orbit radius. A separately assessed full-orbit computation would be a different discriminating test.
