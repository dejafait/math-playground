# Numerical semisimplification as a marked-category transport objection — stopped

WHY IT FAILS: [L123](../lemmas/L123-fixed-cutoff-numerical-log-link-audit.md) checks that the cited integration-class map preserves an already specified numerical cutoff, while semisimplifying the measure space H itself does not encode that cutoff. The source assigns marked comparison to (sQ3)/(sQ4), before the numerical stage (sQ5). Demanding that the numerical map construct a functor of categories marked to the output determinant therefore imposes an unused stronger premise. This stops that objection, not an audit of the actual structured comparison. No native-pilot membership, full formal-quotient identification or IUT flaw is established. Reopening this particular objection requires a source use that actually substitutes the numerical map for missing marked data; another pointwise-logarithm example or the observation that Rss(H) is unbounded is insufficient.
