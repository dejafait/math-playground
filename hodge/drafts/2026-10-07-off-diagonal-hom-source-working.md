# Off-diagonal relative-Hom source review — working record

2026-10-07. Literature-only; no calculation, new lemma or separation claim.
The exact target remains the saved charge-seven off-diagonal test. Inputs
inspected: L060 hypotheses and all-fibre statement, L063 hypotheses and
placement, L065 hypotheses and normalization conclusion. The family is
actual only conditionally on F existence. All fibres have the same H and
Mukai vector (2,0,-5); global point separation is not an input.

Primary source statements read so far: Huybrechts--Lehn (1997),
Proposition 1.2.7 and Corollary 1.2.8, printed pp. 11--12; Stacks
36.30.4 (0B91), 36.22.5 (08IB), and 36.31.1 (0BDI), including the
Tor-independence and finite-complex/rank proof cases. These supply a
derived fibre test and jumping-locus tools, not the required vanishing.
Sources: https://ncatlab.org/nlab/files/HuybrechtsLehn.pdf#page=23,
https://stacks.math.columbia.edu/tag/0B91,
https://stacks.math.columbia.edu/tag/08IB,
https://stacks.math.columbia.edu/tag/0BDI.

Stronger comparisons: Bondal--Orlov, arXiv:alg-geom/9506012v1,
Theorem 1.1, printed p. 5, explicitly requires all-degree orthogonality
of distinct point images. It cannot supply unknown Hom vanishing.
Markman, arXiv:math/0009109v4, Theorem 1, printed pp. 2--3, concerns
the diagonal of the full smooth stable moduli space and a Chern class
in its dimension. Its introduction allows a noncomplete moduli space;
do not impose v-genericity as an obstruction to that version. Essential
proof cases and the quasi-universal extension remain to be inspected.
The later arXiv:math/0406016v3 statement, Theorem 8, has a different
explicit v-generic scope; it should not replace the earlier statement.

Review completed: Markman's proof through (11) and all Lemma 4
hypotheses were inspected, together with the Section 3 opening.
The complete semi-universal construction is not imported. The earlier
proof itself distinguishes vanishing relative Ext^0 sheaf from nonzero
Hom at diagonal fibres and requires a support/codimension/rank condition
not justified for an arbitrary parameter subfamily. The final assessment
records EXPLORE for the same target. No conclusion follows from the
single-projection IT property, Euler class alone or a moduli-diagonal
formula with an unjustified dimension substitution. This record contains
source observations only; the current continuation is in PROGRESS.md.
