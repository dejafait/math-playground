# Attempt 033 — Uniform doubled rank-two third-Chern exclusion

Date: 2026-10-03. Outcome: the third-Chern test gives a conditional
exclusion but does not exclude all allowed final chambers and residues.
The exact test was completed in one mathematical turn; the previous
doubled-source construction window remains closed.

The canonical calculation and surviving data are in
[L044](../lemmas/L044-rank-two-doubled-third-chern-constraint.md).

**WHY IT FAILS.** The normalized rank-two third character forces the
elliptic fibre into W, so chambers omitting it fail independently of
the original factor residues. But two integral root reflections give
an actual final ample chamber retaining W_0 and the fibre. Signed third
finite differences in that same integral lattice change the two third
moments without changing rank or the first two character components;
they make an explicit virtual rank-two class pass c_3=0. Thus this
identity supplies no uniform nonexistence theorem. A virtual class
still supplies no exact presentation, locally free bundle, stability
or transverse cycle transport. Its fourth Chern class is untested;
more signed residue sampling alone does not reopen the old recipe.
