# L001 — The low-dimensional boundary and the primitive fourfold gap

## Hypotheses

Let X be a connected smooth projective complex variety of complex dimension n, let h be an ample integral divisor class, and write L(alpha) = h cup alpha. Use Hdg^p(X) and A^p(X) as defined in [the target statement](../foundations/01-target-and-scope.md).

## Conclusion

For every n, A^p(X) = Hdg^p(X) when p = 0, 1, n-1, or n, retaining only values in 0 <= p <= n. Consequently the rational Hodge conjecture holds for n <= 3.

For n = 4 there is a rational direct sum

\[
\operatorname{Hdg}^2(X)=
\bigl(P_h^4(X,\mathbb Q)\cap\operatorname{Hdg}^2(X)\bigr)
\oplus L\operatorname{Hdg}^1(X),
\qquad
P_h^4=\ker(L:H^4\to H^6).
\]

The second summand is algebraic. Hence the rational Hodge conjecture for a fourfold X is equivalent to algebraicity of all its primitive rational (2,2)-classes. This is a reduction within dimension four, not a reduction of the entire conjecture to fourfolds.

## Proof

Use the named standard results recorded in [the standard inputs](../foundations/02-standard-inputs.md).

The degree-zero group is generated by the class of X, and the top-degree group is generated by the class of a point, so p = 0 and p = n are immediate. For p = 1, Lefschetz (1,1) supplies a rational divisor for every rational Hodge class. This also handles every case when n <= 2.

For n >= 2, Hard Lefschetz gives the rational isomorphism

\[
L^{n-2}:H^2(X,\mathbb Q)\xrightarrow{\sim}H^{2n-2}(X,\mathbb Q).
\]

Its complexification shifts every Hodge summand by (n-2,n-2). Since it is bijective, the inverse image of a class of type (n-1,n-1) is of type (1,1); it is rational because the original map is a rational isomorphism. Lefschetz (1,1) makes that inverse image a rational divisor class. Multiplying by h^(n-2) is an algebraic intersection product and gives the desired codimension-(n-1) cycle class. No algebraic correspondence realizing the inverse Lefschetz map has been assumed. The cases listed exhaust all p for n <= 3.

Now let n = 4 and alpha be in Hdg^2(X). Hard Lefschetz says that L^2: H^2(X,Q) -> H^6(X,Q) is an isomorphism. Set

\[
\gamma=(L^2)^{-1}(L\alpha),\qquad \beta=\alpha-L\gamma.
\]

The class L alpha has type (3,3), so gamma is a rational (1,1)-class and beta is a rational (2,2)-class. The defining equation gives L beta = L alpha - L^2 gamma = 0. If L gamma is primitive, then L^2 gamma = 0, and Hard Lefschetz forces gamma = 0; this proves directness. Finally L gamma is algebraic by Lefschetz (1,1) and intersection with h. Algebraicity of the primitive summand therefore implies algebraicity of every codimension-two Hodge class. The converse is immediate, and the other codimensions of a fourfold have already been handled.
