## WHY IT FAILS

For each horizon, an unbounded family inside the odd cylinder 47 modulo
243 has initial valuation exactly 4 and no smaller residue-20 companion
meeting its path within that horizon on either clock. The post-exit
odd run can be arbitrarily long while the initial valuation stays fixed.
L026 preserves actual paths, both slope cases, zero clocks and strict
order at the original root; the anchor value 47 is treated separately.
Any clock depending only on that initial valuation has one finite value
at 4 and is defeated, even after finite base exceptions. This stops that
duration coordinate, not clocks using the full height or later arithmetic,
and supplies no nonconvergent positive integer.
